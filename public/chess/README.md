# Chess pieces

`pieces/*.svg` — the "cburnett" set drawn by [Colin M.L. Burnett](https://en.wikipedia.org/wiki/User:Cburnett), the
pieces used on Wikipedia and Lichess.

- Originals: Wikimedia Commons, e.g. [Chess klt45.svg](https://commons.wikimedia.org/wiki/File:Chess_klt45.svg), offered by
  the author under any of: BSD licence, GPL, GFDL / CC BY-SA 3.0.
- These files are the optimised copies from [lichess-org/lila](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett)
  (listed there as GPLv2+). They are unchanged.

File names: colour (`w`/`b`) + piece (`K` king, `Q` queen, `R` rook, `B` bishop, `N` knight, `P` pawn).

Move rules come from [chess.js](https://github.com/jhlywa/chess.js) (BSD 2-Clause), an npm dependency.
